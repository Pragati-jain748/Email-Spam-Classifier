# 📧 Email Spam Classifier

A Full Stack Machine Learning project that classifies emails as **Spam** or **Ham (Safe Email)** using a Logistic Regression model.

## 🚀 Features

- 📩 Detects Spam and Safe Emails
- 🤖 Machine Learning based prediction
- ⚡ FastAPI backend for ML inference
- 🌐 Express.js backend
- 💻 React frontend
- 🔄 Real-time prediction
- 🎨 Simple and responsive user interface

---

### Frontend

### Backend

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Email-Spam-Classifier.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
node index.js
```

### FastAPI

```bash
cd ml_api
pip install -r requirements.txt
uvicorn app:app --reload
```
